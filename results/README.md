# Results

Everything here is generated by the scripts. Nothing is edited by hand.

| Path | Produced by | Committed? |
|---|---|---|
| `audit/audit.json`, `audit/audit_summary.md`, `audit/labels.csv`, `audit/per_subject_label_counts.csv` | `audit_dataset.py` | yes |
| `audit/manifest.csv` | `audit_dataset.py` | no (lists every file; regenerate locally) |
| `runs/<run_id>/results.jsonl` / `results.csv` | `run_experiments.py` | yes |
| `runs/<run_id>/provenance.json`, `eligibility.csv`, `method_status.json` | `run_experiments.py` | yes |
| `runs/<run_id>/predictions.csv.gz`, `selections.json.gz` | `run_experiments.py` | no (large; fully regenerable) |
| `runs/LATEST` | `run_experiments.py` | yes (ID of the run the tables come from) |
| `tables/*.csv`, `tables/*.json` | `run_experiments.py`, `analyze_errors.py`, `generate_report_assets.py` | yes |
| `figures/fig*.png|pdf` | `audit_dataset.py`, `generate_report_assets.py` | yes |
| `figures/local_only/` | `analyze_errors.py` | **never** (contains dataset imagery) |

## `results.jsonl` schema (one record per method × fold × seed × budget × noise condition)

| Field | Meaning |
|---|---|
| `run_id` | run identifier (timestamp + config hash) |
| `method` | method name (see `fewgaze.extraction.method_registry`) |
| `kind` | `trained` (logistic-regression head) or `zeroshot` (no FewGaze labels) |
| `condition`, `noise_rate` | `clean` / 0.0, or `noise` with the flip rate |
| `budget` | labelled examples per class (`5`…`100`, `all`); `0` for zero-shot |
| `seed`, `fold` | selection seed (−1 for zero-shot) and outer fold index |
| `n_train`, `n_train_pos`, `n_flipped` | training-set size, positives after any flips, number of flipped labels |
| `selection_key` | key into `selections.json.gz` (`f{fold}_s{seed}_k{budget}`) holding the exact sample IDs and flip mask |
| `n_test`, `n_test_pos`, `n_test_subjects` | held-out images, positives and subjects |
| `auroc`, `balanced_accuracy`, `sensitivity`, `specificity`, `tp`, `fn`, `fp`, `tn` | test metrics (threshold 0.5); NaN / −1 where undefined |
| `fit_seconds`, `predict_seconds` | wall-clock time of the logistic-regression head |
| `status`, `error` | `ok`, `unavailable` (budget cannot be supplied) or `error` with a message |

## Summary tables

* `learning_curves.csv`: estimate (mean over fold × seed), subject-bootstrap 95 % CI, SD across runs,
  and image/subject counts, for each method × condition × budget × metric.
* `paired_differences.csv`: prespecified ΔAUROC comparisons with paired-bootstrap CIs.
* `head_pose_auroc.csv`, `per_subject_auroc.csv`, `error_rates_by_condition.csv`,
  `error_category_counts.csv`, `error_examples.csv` (image IDs only), `confusion_matrices.json`,
  `efficiency.csv`, `classifier_timing.csv`, `extraction_summary.json`, `run_status_counts.csv`.
